# CitationGuard 🛡️
### Prompt-Aware Detection and Verification of Hallucinated Citations in Large Language Models

CitationGuard is a citation-verification pipeline designed to detect hallucinated or inaccurate academic references generated by Large Language Models (LLMs). It combines DOI verification, multi-source scholarly retrieval, metadata similarity, and rule-based validation to identify suspicious citations.

## 🚀 Features

- **Prompt-Aware Classification** — Identifies responses where academic citations are expected.
- **Citation Parsing** — Extracts titles, authors, publication years, venues, and DOIs.
- **DOI Verification** — Checks DOI records using Crossref and DataCite.
- **Multi-Source Retrieval** — Retrieves publication records from Crossref, Semantic Scholar, and OpenAlex.
- **Candidate Ranking** — Ranks retrieved publications using metadata similarity.
- **Metadata Validation** — Checks consistency across bibliographic fields.
- **Hallucination Scoring** — Assigns a score from 0 to 100 to help identify citation inconsistencies.
- **Verification Results** — Classifies citations as verified or flags them for further review.

## ⚙️ Workflow

1. Input a prompt and an LLM-generated response.
2. Identify and extract citations.
3. Parse bibliographic metadata.
4. Verify available DOIs.
5. Retrieve candidate publications from scholarly databases.
6. Rank candidates using metadata similarity.
7. Validate metadata and calculate the hallucination score.
8. Generate verification results.

## 🛠️ Tech Stack

- **Language:** Python
- **String Matching:** RapidFuzz
- **Metadata Sources:** Crossref, DataCite, Semantic Scholar, OpenAlex
- **Approach:** Rule-based validation, metadata comparison, and similarity scoring

## 📊 Evaluation Results

CitationGuard was evaluated on a benchmark of **600 citation instances** derived from 100 real computer science papers.

| Configuration | Accuracy | Precision | Recall | F1-Score |
|---|---:|---:|---:|---:|
| Baseline | 79.67% | 94.16% | 80.60% | 86.85% |
| Author Validation | 89.33% | 94.86% | 92.20% | 93.51% |
| Venue Validation | 80.67% | 94.24% | 81.80% | 87.58% |
| Author + Venue Validation | **90.33%** | **94.92%** | **93.40%** | **94.15%** |

Combining author and venue validation improved the F1-score from **86.85% to 94.15%** and recall from **80.60% to 93.40%**. False negatives decreased from 97 to 33.

### Benchmark Composition

- 100 genuine citations
- 500 altered citations labelled as hallucinated
- Five alteration categories: DOI mismatch, corrupted authors, wrong year, wrong venue, and plausible fabricated entries

**Evaluation note:** A subsequent audit identified 24 altered citations whose replacement fields were unchanged from the originals. These cases were retained in the originally submitted evaluation and may affect the reported results.

## ⚠️ Limitations

- The benchmark uses controlled alterations of real citation records and may not represent all hallucinations generated naturally by LLMs.
- Verification depends on the availability and accuracy of external scholarly metadata.
- Scoring weights and thresholds were selected manually.
- The system has not been experimentally compared head-to-head with CiteCheck.

## 🔮 Future Work

## 📌 Disclaimer
